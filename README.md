# BJ School Calendar — Google Apps Script

เว็บ SPA ปฏิทินปฏิบัติงานและกิจกรรม โรงเรียนเบญจมราชูทิศ จังหวัดจันทบุรี

เวอร์ชันนี้ใช้ Google Apps Script อ่านข้อมูลจาก Google Sheets ต้นฉบับทั้ง 3 ฝ่ายโดยตรง หน้าเว็บจึงได้รับข้อมูลปัจจุบันทุกครั้งที่เปิดเว็บหรือกดปุ่ม **ดึงข้อมูลล่าสุด**

## ไฟล์สำหรับ Google Apps Script

- `Code.gs` อ่านและรวมข้อมูลจาก Google Sheets
- `index.html` หน้าเว็บ SPA
- `appsscript.json` การตั้งค่าโครงการและเขตเวลา

ไฟล์ `events.json` ใช้เป็นข้อมูลสำรองเฉพาะเมื่อเปิดหน้าเว็บนอก Google Apps Script เช่น GitHub Pages

## แหล่งข้อมูล

1. ฝ่ายบริหารงานทั่วไป
2. ฝ่ายบริหารงานบุคคลและกิจการนักเรียน
3. ฝ่ายบริหารงานวิชาการ

โค้ดรองรับชีตหลายปีการศึกษา โดยอ่านข้อมูลเป็นชุดคอลัมน์ `วันที่ | กิจกรรม | ผู้รับผิดชอบ` และรวมรายการซ้ำให้อัตโนมัติ

## วิธีนำไปใช้งาน

1. ไปที่ [Google Apps Script](https://script.google.com/) แล้วสร้างโปรเจกต์ใหม่
2. สร้างไฟล์ `Code.gs` และ `index.html` แล้วคัดลอกโค้ดจาก Repository
3. เปิด Project Settings และเลือกแสดงไฟล์ manifest จากนั้นแทนที่ด้วย `appsscript.json`
4. กด **Deploy > New deployment > Web app**
5. ตั้งค่า **Execute as: Me**
6. ตั้งค่า **Who has access** ตามกลุ่มผู้ใช้งานที่ต้องการ
7. อนุญาตสิทธิ์เข้าถึง Google Sheets ทั้ง 3 ไฟล์เมื่อระบบร้องขอ
8. เปิด URL ของ Web App เพื่อใช้งาน

## ความสามารถ

- เริ่มต้นด้วยมุมมองรายการและเรียงกิจกรรมใหม่ไปเก่า
- สลับมุมมองรายการและปฏิทิน
- ค้นหาและกรองตามปีการศึกษา ภาคเรียน และฝ่ายงาน
- เลือกธีมแสดงผลได้ 3 ธีม
- เปิด Google Sheets ต้นฉบับของแต่ละฝ่าย
- ดึงข้อมูลล่าสุดจาก Google Sheets โดยไม่ต้องแก้ไขโค้ด
- รองรับคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ
