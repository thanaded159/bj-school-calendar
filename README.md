# BJ School Calendar

เว็บ SPA ปฏิทินปฏิบัติงานและกิจกรรม โรงเรียนเบญจมราชูทิศ จังหวัดจันทบุรี

## ความสามารถ

- แสดงกิจกรรมแบบรายการและปฏิทิน
- ค้นหาและกรองตามปีการศึกษา ภาคเรียน และฝ่ายงาน
- เรียงกิจกรรมจากใหม่ไปเก่า
- เลือกธีมแสดงผลได้ 3 ธีม
- เชื่อมโยง Google Sheets ต้นฉบับของแต่ละฝ่าย
- ดึงข้อมูลล่าสุดโดยไม่ใช้แคช
- รองรับคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ

## ไฟล์สำคัญ

- `index.html` หน้าเว็บ SPA
- `events.json` ข้อมูลกิจกรรม
- `scripts/extract_events.py` สคริปต์เตรียมข้อมูลจากไฟล์ Excel ต้นฉบับ

พัฒนาโดยงานเทคโนโลยีสารสนเทศและการสื่อสาร (ICT) โรงเรียนเบญจมราชูทิศ จังหวัดจันทบุรี
